# مالي — Mohamed (PWA V2)

## نشره على GitHub Pages
1. أنشئ حساب GitHub مجاني.
2. أنشئ Repository جديد باسم: mohamed-finance
3. ارفع كل الملفات الموجودة في هذا المجلد إلى جذر الـ Repository.
4. افتح Settings > Pages.
5. اختر Deploy from a branch.
6. اختر branch: main و folder: /root ثم Save.
7. انتظر دقيقة أو دقيقتين وسيظهر رابط التطبيق.
8. افتح الرابط من Safari على iPhone ثم Share > Add to Home Screen.

## الخصائص
- يعمل بدون إنترنت بعد أول فتح.
- البيانات محفوظة محليًا على نفس الجهاز.
- نسخ احتياطي JSON واسترجاع.
- تصدير CSV.
- تقارير شهرية وطباعة PDF.
- وضع ليلي.
- أسعار ذهب وفضة يدويًا أو عبر API Key اختياري.
