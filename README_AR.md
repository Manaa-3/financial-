# مالي — Mohamed V3

## أهم التحديثات
- تقويم ميلادي فقط.
- بحث وفلترة في العمليات.
- صورة فاتورة لكل مصروف.
- تحليل شهري وسنوي.
- متوسط سعر شراء الذهب والفضة، والربح والخسارة المحققة وغير المحققة.
- تصدير PDF وExcel.
- وضع ليلي وتصميم محسن للموبايل.
- مزامنة اختيارية مجانية عبر Supabase.

## تحديث التطبيق على GitHub
1. افتح Repository الحالي.
2. اضغط Add file > Upload files.
3. ارفع كل الملفات الموجودة هنا.
4. وافق على استبدال الملفات الحالية.
5. اضغط Commit changes.
6. انتظر GitHub Pages دقيقة أو دقيقتين.
7. على الهاتف اقفل التطبيق وافتحه. لو ظهرت النسخة القديمة، امسح بيانات الموقع أو احذف الأيقونة وأعد إضافتها.

## المزامنة السحابية الاختيارية
1. أنشئ مشروع مجاني على Supabase.
2. افتح SQL Editor.
3. نفّذ محتوى ملف SUPABASE_SETUP.sql.
4. من Project Settings > API انسخ Project URL و anon public key.
5. أدخلهما في التطبيق.
6. أنشئ حسابًا من داخل التطبيق ثم سجّل الدخول.
7. استخدم رفع للسحابة واسترجاع من السحابة.

ملاحظة: بيانات صور الفواتير قد تجعل النسخة الاحتياطية كبيرة، لذلك صغّر التطبيق الصور تلقائيًا.
