# مالي V5 React Alpha
هذه أول مرحلة من إعادة البناء الاحترافي.

## التحديث على GitHub
1. فك الضغط.
2. ارفع كل الملفات إلى Repository الحالي واستبدل الملفات القديمة.
3. Commit changes.
4. انتظر GitHub Pages.
5. احذف أيقونة التطبيق القديمة وأعد إضافتها من Safari.

## الحماية
افتح: الإعدادات > الحماية > أدخل PIN > حفظ.
ثم اضغط علامة القفل أعلى التطبيق.
